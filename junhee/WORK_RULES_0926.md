## 1. handoff 요약 — 화면에 보여줄 항목의 기준

1. **규제** — 입력 HSK와 연결된 통제번호·품목명 / 목적국 수입규제 기록(규제 유형·대상 원산지·진행상황·기간) / 거래처명의 CSL 검색 결과(명칭·주소·명단 출처·기재기간).
   → '후보·기록이 발견됐다'까지만. '수출금지·거래금지'로 표시하지 않고, 기록이 없다고 '규제 없음'으로 판정하지 않는다.
2. **시장성** — 목적국 수입시장 규모(연간·월별) / 한국의 해당국 수출액 / 성장률(전년동기·최근3개월 전년동기·3년 CAGR) / 한국산 수입점유율 / WSTS 업황.
   → 세 가지(목적국 수입액, 한국 수출액, WSTS 산업매출)는 서로 다른 정보로 구분. 성장률은 필요한 기간 자료가 있을 때만.
3. **가격** — 무역통계 kg당 단가 / 기준 대비 단가 / WTO 관세 참고치와 날짜별 이력 / 결제통화 참고환율과 추세 / 한국은행 수출입물가지수(실제 수록 분류) / 운송비 참고(해상수출·해상수입·항공수입 구분).
   → 통계 단가는 실제 판매가가 아니고, 관세 참고치는 확정 세율이 아니다. 물가지수를 반도체 개별 가격으로, 항공수입 운송비를 항공수출 견적으로 표시하지 않는다.
4. **물류** — 인천공항 화물편 일정 / 운항 횟수 / 선박 입출항 기록. 공항·항만·국가 기준 정보이며 직항·배송시간·운송 가능 여부를 확정하지 않는다.
5. **안정성** — 목적국 월별 수입금액·전월비 / 변동계수 CV / 급감(전월비 −20% 이하) 이력·횟수·빈도 / 보조: 한국의 해당국 수출 변동, 결제통화 환율 변동성, WSTS 변동. 과거 변동이지 미래 손실 확률이 아니다.

- **공통**: 회사·제품명, 입력 HS와 실제 분석 HS, 목적국, 자료기간·기준일·출처, 계산 근거, 자료 부족 여부, 실제 0과 자료 없음 구분. 자료 없는 항목은 '미확인' 또는 '자료 부족'.
- **점수**: 평가 기준과 산출값이 확정된 뒤 추가 예정 → 이번에는 점수를 계산·표시하지 않는다.
- **제외**: 수출 가능·금지 확정, 허가·인증 충족, 실제 적용 관세·FTA 절감액, 기업 이익률, 직항·배송시간·납기·운송 가능 여부.

## 3. 보안

- API 키 값을 출력·기록하지 않는다. `.env`, `*api 키*.txt`, `credentials/` 는 읽지도 커밋하지도 않는다.
- `git add .` / `git add -A` 금지. push 금지. 커밋은 내가 요청할 때만.

## 4. 데이터 원칙

- 원본(`junhee/data/raw/**`, `junhee/data/samples/*.xlsx`) 수정 금지.
- 없는 숫자·URL을 만들지 않는다. 가상 회사 자료는 '가상 데이터 · 시연용'으로 표시한다.
- 실제 기업명(삼성전자·SK하이닉스)을 화면·JSON에 쓰지 않는다(근거는 엑셀 '근거' 시트에만 있음). 스크립트는 '근거' 시트를 읽지 않는다.

## 5. 상태 문구

색만으로 구분하지 않고 글자로 쓴다: **확인됨 / 자료 부족 / 미확인(연동 전) / 검색 결과 없음(판정 아님) / 검색 불가 / 0(실제 값)**.
