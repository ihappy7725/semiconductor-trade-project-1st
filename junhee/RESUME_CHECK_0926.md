# 중단 작업 재점검 — 2026-09-26

기존 index3 기반 상세 화면, 물류 샘플 3개, 업로드 양식 다운로드를 유지하고 실행 검증했다.

## 보완

- 상세 패널에서 표 본문이 헤더 높이로 축소되고 다른 카드와 겹치던 CSS 수정. 내용은 창 안에서 스크롤한다.
- KPI 숫자가 일반 span 스타일을 상속해 작게 보이던 문제 수정.
- 결측 안내에 원본 엑셀 행 번호 추가(표시된 식별자 최대 6개에 대응하는 모든 행).
- 검증 JSON 조회 실패 시 분석 중단. 중복 제출 방지 및 업로드 제출마다 확인.
- 수정한 임의 파일을 다시 업로드하면 분석된다는 부정확한 안내 수정.

## 검증

앱 실행 후 `python junhee/scripts/check_dashboard_browser.py` 실행.
샘플 파일 실제 업로드, 결측 확인 취소/진행, 엑셀 다운로드와 시트 구조,
3개 회사 × 상세 탭 5개, 차트 데이터 및 JavaScript 오류, 검증 조회 실패 시 중단을 검사한다.
새벽 회사는 결제통화가 없어 가격 환율 차트를 만들지 않는 것이 정상이다.

JSON 재생성: `python junhee/scripts/build_company_items.py` → `python junhee/scripts/publish_static.py`.
원본 샘플 엑셀은 이 재점검에서 변경하지 않았다.
