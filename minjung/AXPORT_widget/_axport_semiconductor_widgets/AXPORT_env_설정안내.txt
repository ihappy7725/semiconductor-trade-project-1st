AXPORT .env 설정 안내
====================

1. 파일 위치
C:\Users\user\Desktop\test1\.env

이 파일은 이미 만들어져 있습니다. VS Code에서 열어 값을 입력하세요.
프로젝트 최상위의 .env 한 개만 사용합니다. 하위 폴더에 새 .env를 만들지 마세요.
기존에 다른 팀원이 넣은 설정은 지우지 말고, 아래 항목만 확인하세요.

2. 입력할 항목

# 임시확인용 — 실제 API 키는 GitHub에 올리지 마세요.
AXPORT_DATA_MODE=demo
EXCHANGERATE_API_KEY=
THENEWS_API_KEY=
CUSTOMS_API_KEY=
AXPORT_WEATHER_JSON=

3. 항목별 의미

AXPORT_DATA_MODE
- demo: API를 호출하지 않고 예시 데이터를 표시합니다.
- live: 실제 환율·뉴스 API 및 수출 통계 JSON을 사용합니다.
- 실제 키를 넣은 뒤 이 값을 live로 바꿔야 실제 연결을 시도합니다.
- 화면에서 예시 문구를 지웠더라도 demo 모드의 숫자와 헤드라인은 실제 데이터가 아닙니다.

EXCHANGERATE_API_KEY
- 본인이 발급받은 ExchangeRate-API 키를 = 뒤에 입력합니다.
- USD/KRW, USD/CNY, EUR/KRW에 사용합니다.
- 무료 플랜은 일별 기준환율이며 실시간 호가는 아닙니다.

THENEWS_API_KEY
- The News API(thenewsapi.com)에서 받은 API 키를 입력합니다.
- newsapi.ai, newsapi.org의 키와는 다릅니다.
- 한국어·영어·일본어·중국어의 원문 기사를 각각 검색합니다.
- 언어 변경은 동일 기사의 자동 번역이 아닙니다.

CUSTOMS_API_KEY
- 관세청 품목별 수출입실적 API의 서비스키를 입력하는 항목입니다.
- 현재 웹 화면은 이 키만 넣는다고 수출 통계를 자동으로 수집하지는 않습니다.
- 별도 관세청 수집 스크립트를 실행할 때 사용합니다.

AXPORT_WEATHER_JSON
- 관세청 수집 스크립트로 생성·검증한 수출 통계 JSON의 절대 경로를 입력합니다.
- 예: C:/Users/user/Desktop/test1/axport_weather_202608.json
- 위 경로는 예시입니다. 실제 파일이 있어야 합니다.
- 임의의 JSON 또는 news_test_results.json은 사용할 수 없습니다.
- 현재 화면은 이 파일의 반도체 4개 분류와 전년 동기 누계 비교 값을 읽습니다.
- live 모드에서 이 항목이 비어 있으면 수출 실적 미연결 안내가 표시됩니다.

4. 실제 데이터로 바꾸는 순서

① .env에서 EXCHANGERATE_API_KEY와 THENEWS_API_KEY에 본인의 실제 키를 입력합니다.
② 수출 통계 JSON을 준비했다면 AXPORT_WEATHER_JSON에 실제 경로를 입력합니다.
③ AXPORT_DATA_MODE=live로 변경하고 저장합니다.
④ 실행 중인 터미널에서 Ctrl+C를 누릅니다.
⑤ test1 폴더에서 다시 실행합니다.

python app.py

⑥ 브라우저에서 아래 주소를 열고 새로고침합니다.
http://127.0.0.1:5073/app

.env 변경은 서버 재시작이 필요합니다. 브라우저 새로고침만으로는 반영되지 않습니다.
키가 없거나 호출이 실패한 항목은 오류/미설정 안내가 표시됩니다.
운영체제 환경변수에 같은 이름이 설정되어 있다면 그 값이 .env보다 우선합니다.

5. 주의

- 키를 따로 요청하거나 TXT로 공유할 필요는 없습니다. 본인의 .env에 직접 입력하세요.
- 실제 키를 넣은 .env를 GitHub에 커밋하지 마세요.
- 이 TXT 파일에는 실제 키를 포함하지 않았습니다.
