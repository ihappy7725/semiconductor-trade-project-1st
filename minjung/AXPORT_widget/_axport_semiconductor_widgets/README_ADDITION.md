# 기존 AXPORT 팀 프로젝트용 추가 위젯

> 2026-09-26 통합 완료: 현재 경로와 실행·환경 설정은 [../INTEGRATION.md](../INTEGRATION.md)를 따르세요. 아래 내용은 최초 전달 당시 기록입니다. 현재 `python app.py`에도 위젯이 연결되어 있습니다.

이 폴더는 독립 웹사이트가 아닙니다. 상위 폴더의 **실제 `app.py`와 `templates/workspace.html`을 읽어서**, 기존 화면 위에 위젯만 추가합니다. 팀원의 JS·CSS·기업 데이터·챗봇은 원래 `/static/` 경로에서 그대로 불러옵니다.

## 실행

`test1` 폴더에서:

```powershell
python -B .\_axport_semiconductor_widgets\run_preview.py
```

화면: <http://127.0.0.1:5075/app>

프로젝트 밖에 폴더를 둘 때:

```powershell
python -B run_preview.py --project-root "C:\Users\user\Desktop\test1"
```

기존 `start.ps1` 또는 `python app.py`는 기존 화면으로 실행됩니다. 기존 실행 파일을 수정하지 않았기 때문에, **추가 화면을 볼 때는 위의 새 명령**을 사용해야 합니다. 새 프로세스에서만 `/app`의 HTML 응답에 추가 마크업·스타일·스크립트를 연결합니다. 기존 서버와 별도 포트(5075)를 사용합니다. 종료: Ctrl+C.

비교용 원래 작업공간: <http://127.0.0.1:5075/_axp_semiconductor/original>
홈 `/`과 기존 정적 파일 경로는 그대로입니다.

## 이번 변경

- 처음 진입·새로고침하면 기존 분석 창은 닫힌 상태입니다. 서버 응답부터 `hidden`으로 제공하여 잠깐 열렸다 사라지는 현상도 방지합니다.
- 왼쪽의 원래 분석 아이콘을 클릭하면 **기존 분석 창**이 열립니다.
- 중앙: HS·대상국·기업명·파일 업로드 카드.
- 오른쪽: 환율, 무역 뉴스, 수출기상도 카드.
- 상단: 서울·뉴욕·런던·상하이 초 단위 시계. 서머타임 자동 적용.
- 기존 한빛반도체/대성일렉트로닉스 파일 아이콘, 분석 탭, 가중치, 보고서, 챗봇 코드를 그대로 사용합니다.
- 중앙 `팀 샘플 불러오기`는 기존 `샘플 파일 사용` 처리로 연결됩니다. 새 가짜 샘플이나 별도 점수 화면을 만들지 않았습니다.
- 중앙 분석 버튼은 기존 `analysis-form`을 제출합니다. 기존 샘플 등록·해시 대조·기업 점수 로딩 규칙을 변경하지 않습니다.
- 위젯 편집 모드: 헤더 드래그 또는 방향키 이동. Shift+방향키는 40px 이동. 삭제·휴지통 복원·새로고침 후 배치/숨김 유지.
- 휴지통 한 번 클릭: 위젯 복원. 그 창의 `기존 파일 휴지통 열기` 또는 원래 아이콘 더블클릭: 기존 파일 휴지통.
- 배치 초기화는 위젯 위치만 초기화합니다. 숨긴 위젯은 전체 복원으로 되돌립니다.
- 기존 언어 선택기와 연동하여 한국어·영어·일본어·중국어 위젯 표시를 바꿉니다.

## 파일과 충돌 방지

```text
test1/
├── app.py, templates/, static/, JH/, JH2/, junhee/  ← 수정 없음
├── .env                                          ← 없을 때만 새 파일, 기존 것은 유지
└── _axport_semiconductor_widgets/                 ← 추가 전용 폴더
    ├── run_preview.py
    ├── README_ADDITION.md
    ├── verify_extension.py
    └── sx_widgets/
        ├── __init__.py                            ← 기존 응답에 추가 연결
        ├── providers.py
        ├── weather.py
        ├── templates/widgets.html                 ← 위젯 조각 마크업
        └── static/
            ├── widgets.css                       ← sx 전용 스타일
            ├── widgets.js                        ← 기존 UI 연결·위젯 조작
            └── widget-text.js                    ← 추가 위젯 번역
```

- 기존 `workspace.html/css/js`를 복사하거나 대체하지 않습니다.
- 새 DOM ID는 `sx-`, 스타일은 `sx-` 및 `axsx-preview`, 새 URL은 `/_axp_semiconductor/`를 사용합니다.
- 기존 언어 설정을 사용하고, 위젯 위치·숨김만 별도 `axsx.team.widgets.v1` 저장 키를 사용합니다.
- 새 URL/블루프린트 이름이 이미 존재하면 실행을 중단합니다. 팀의 HTML 연결 지점이 바뀌면 원본을 고치는 대신 추가 어댑터를 검토해야 합니다.
- 팀 저장소에는 `_axport_semiconductor_widgets` 폴더만 선택해서 추가할 수 있습니다. **실제 키가 들어간 `.env`는 커밋하지 마세요.** 기존 `.gitignore`도 수정하지 않았습니다.
- 향후 팀원 변경과의 충돌 가능성까지 절대적으로 보장할 수는 없습니다. 이번 버전은 원본 파일을 수정하지 않고, 현재 팀 구조를 기준으로 연결·검증했습니다.

## API와 파일 처리 범위

기본은 **예시 데이터**입니다. 루트 `.env`의 `AXPORT_DATA_MODE=live` 및 키 설정 후 실제 모드로 전환하고 서버를 재시작합니다. 실제 호출 성공은 이번 UI 통합 작업에서 검증하지 않았습니다.

```dotenv
# 임시확인용 — 실제 키는 나중에 입력, Git 커밋 금지
AXPORT_DATA_MODE=demo
EXCHANGERATE_API_KEY=
THENEWS_API_KEY=
CUSTOMS_API_KEY=
AXPORT_WEATHER_JSON=
```

`.env`는 **test1 최상위 한 곳만** 읽습니다. 추가 폴더 안에는 `.env`를 만들지 않습니다. 기존 `.env`가 있으면 덮어쓰지 않습니다.

- 환율: ExchangeRate-API, 무료 일별 기준환율. 실시간 호가가 아닙니다. 전일 데이터가 확보되지 않았으면 전일 대비를 임의로 생성하지 않습니다.
- 뉴스: 앞서 합의한 The News API. 언어 변경은 동일 기사의 자동 번역이 아닌 해당 언어의 원문 조회입니다. 서버 캐시 2시간, 최대 3건. KOTRA/WTO 크롤러는 추가하지 않았습니다.
- 수출기상도: 메모리(854232), 프로세서·컨트롤러(854231), 기타 IC·부분품(854233/854239/854290), 반도체 소자(8541). HS 자체 분류이며 MTI4 공식 대응표는 아닙니다. 8541은 LED·태양전지 등을 포함합니다. 현재 숫자는 모두 UI 예시입니다.
- 실제 수출 실적은 앞서 제공한 수집 스크립트로 검증한 JSON 경로를 `AXPORT_WEATHER_JSON`에 지정하는 방식입니다. 월별 누계이며 실시간 통계가 아닙니다.
- XLSX/XLS: 기존 분석기로 연결하여 SHA-256으로 등록 샘플 여부를 대조합니다. 임의 파일을 새로 파싱하거나 점수화하지 않습니다. 파일 내용은 브라우저 해시 계산에 사용되며 서버로 업로드하지 않습니다.
- CSV: 파일 선택 미리보기만 지원합니다. 기존 분석기에서 처리하는 것처럼 꾸미지 않습니다.
- 기존 분석기는 선택 조건보다 등록된 샘플의 HS·대상국을 우선합니다. 이 규칙을 바꾸지 않았습니다.
